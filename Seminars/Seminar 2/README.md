## Член-функции
- функции в тялото на клас или структура
- може да бъде в тялото на структурата
- работят с член-данните на обекта
- извикват се от обект

```c++
struct Point {
    int x;
    int y;

    bool isInFirstQuadrant() {
        return p.x >= 0 && p.y >= 0;
    }
}

int main() {
    Point p;
    std::cout << p.isInFirstQuadrant();

    Point* ptr = new Point();
    std::cout << ptr->isInFirstQuadrant();
    delete ptr;
}
```
- компилаторът ги преобразува в обикновена функция с уникално име и един допълнителен параметър - **константен указател към обекта**, т.е. можем да променяме обекта, но не и да пренасочваме указателя
- константни член-функции - константен указател към константен обект, т.е. не можем да променяме член-данните 
- не влияе на размера на структурата

```cpp
struct Test {
    int x = 0;

    void print() const {
        std::cout << "Test";
    }
    void increment() {
        x++;
    }
}

//се преобразува в
void print(const Test* const this) {
    std::cout << "Test";
}
void increment(Test* const this) {
    x++;
}
```

```cpp
int main() {
    Test t;
    t.increment();

    //се преобразува в
    inctrement(&t);
}
```

```cpp
void f(const Test& t) {
    t.increment(); // няма да се компилира
    t.print(); // ще се компилира
}
```

## Жизнен цикъл на обект. Конструктор и деструктор.
### Жизнен цикъл на обект
1. съдаване
2. използване
3. унищожаване


### Конструктор
- член-функция, която се извиква се точно веднъж - при създаване на обекта
- има същото име като класа/структурата
- не се оказва експлицитно тип на връщане - връща констатна референция
- заделя се памет и член-данните се инициализират
- вика конструкторите на член-данните си в реда, в който са декларирани

- компилаторът автоматично генерира конструктор по подразбиране - без параметри
- ако се дефинира конструктор с параметри, конструктор по подразбиране **не се генерира**

```c++ 
Test arr[10]; // вика default-ен конструктор за всеки Test
```
- влагане на класове/структури
```c++
struct A { }
struct B { }

struct X {
    A a;
    B b;
}
```
- конструкторът на X ще извика последователно конструкторите на A и B и след това ще се изпу=ълни тялото на конструктора на X
```c++
X() : a(), b() {}
```

### Деструктор
- член функция, която се извиква точно веднъж - при изтриване на обекта
- има същото име като класа/структурата, но с ~ пред името
- не се оказва експлицитно тип на връщане
- освобождава паметта, заделена за обекта (за динамични обекти трябва експлицитно да се извика `delete`)
- извиква деструкторите на член-данните в обратен ред
- компилаторът автоматично генерира деструктор, ако ние не дефинираме такъв
- използваме ги за изтриване на външни ресурси, на които не сме собственици
```cpp
#include<iostream>

struct A {
    A() {
```

## Абстракция

## Капсулация (encapsulation)
- един от основните принципи в ООП
- ограничаване на достъпа
- интерфейс - функции, достатъчни да се работи с даден клас/структура
- имплементация - подробности за това как работи кода - не винаги искаме потребителите да имат достъп до тях 
- искаме да разделим интерфейса от имплементацията
- помага ни да пазим данните валидни

### Модификатор за достъп
 
| Модификатор за достъп: | Достъп:                         |
|------------------------|---------------------------------|
| private                | В текущия клас.                 |
| protected              | В текущия клас и *наследниците. |
| public                 | За всеки                        |

при **struct** модификаторът за достъп по подразбиране е **public**, а при **class - private**;

## Селектори и мутатори
- публични член-функции които се използват за достъпване (get - селектори) и промяна (set - мутатори) на член-данни, които са декларирани в private/protected секция на един клас
