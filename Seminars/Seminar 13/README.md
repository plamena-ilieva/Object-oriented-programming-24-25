# Шаблони
- параметричен полиморфизъм
- в C++ е образец/шаблон за създаване на класове или функции, които могат да работят с различни типове данни
- компилаторът създава конкретна реализация на шаблона, когато той бъде инстанциран със специфичен тип или стойност
- параметрите на шаблона се заместват с типовете на съответните фактически параметри
- темплейтни класове - класове, в които на някои елементи не им е ясен типът

```c++
#include <iostream>
using namespace std;

template <class T>
T sum(const T& a, const T& b)
{
    return a + b;
}

int main()
{
    int a = 4;
    int b = 9;
    cout << sum<int>(a, b) << endl;

    double c = 3.14;
    double d = 4.5;
    cout << sum<double>(c,d) << endl;
	
    return 0;
}
```

### Template instantiation
- имплицитно инстанциране - функция/клас се инстанцира поради извикване на функция/създаване на обект
- компилаторът трябва да има достъп до пълната дефиниция на шаблона, за да може да генерира конкретна реализация
- пишем темплейтите в .hpp файлове
- експлицитно инстанциране - в cpp файла се указва с какви типове да се генерира

```c++
#include "max.h"

template <typename T>
T max(T a, T b) {
    return (a > b) ? a : b;
}


template int max<int>(int, int);
template double max<double>(double, double);

```

## Темплейтна спецификация
- функция или клас, който се държи различно за конкретен тип

**Задача 1:**
Релизирайте структурата от данни опашка. Опашката трябва да работи с **произволни типове**. След като е добавен един елемент в края на опашката, той ще може да бъде извлечен (премахнат) единствено след като бъдат премахнати всички елементи преди него в реда, в който са добавени.

**Пример**:
 ```c++
int main()
{
	queue<int> q;
	q.push(3);
	q.push(5);
	q.push(10);

	cout << q.peek() << endl; //3
	q.pop();
	
	cout << q.peek() << endl; //5
	q.pop();

	cout << q.peek() << endl; //10
	q.pop();
	
	cout << q.isEmpty() << endl; //1	
}
